# .github

Org-level GitHub metadata for [wslkit](https://github.com/wslkit).

`profile/README.md` is what renders on the organisation's landing page. It is
the only file here anyone sees.

It is a **family** page, not a product page — that distinction is why the org
is named for the domain rather than for any one project (see
[skrog#1](https://github.com/wslkit/skrog/issues/1)). Products can be added,
renamed or retired under it without the org moving again.

The version and status claims go stale first; keep them in step with each
project's README.
