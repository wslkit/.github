# .github

Org-level GitHub metadata for [hawserhq](https://github.com/hawserhq).

`profile/README.md` is what renders on the organisation's landing page. It is
the only file here that anyone sees; everything else in this repository would be
shared issue templates or workflows, and there are none yet.

Keep it in step with [hawser's README](https://github.com/hawserhq/hawser) —
the version and status claims are the two that go stale first.
